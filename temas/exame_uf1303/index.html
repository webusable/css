CSS para Dar estilo ao contido HTML

Qué é CSS?

Do mesmo xeito que HTML, CSS non é unha linguaxe de programación. Tampouco é unha linguaxe de marcado. CSS é unha linguaxe de follas de estilo. CSS úsase para darlles estilo aos elementos HTML: seleccionas os elementos que queres estilizar e estableces valores para as súas propiedades de estilo, que definen como se verán.

Primeiros pasos en CSS

O primeiro que temos que facer é indicarlle ao documento HTML que temos algunhas regras CSS que queremos que utilice. Hai tres formas distintas de aplicar CSS a un documento HTML coas que te atoparás a miúdo:

  • Follas de estilos externas
  • Estilos incrustados para un documento html
  • Estilos en liña para un elemento HTML

Selectores CSS básicos

Un selector CSS é a primeira parte dunha regra CSS. É un patrón de elementos e outros termos que lle indica ao navegador a que elementos HTML debe aplicar os valores das propiedades CSS da regra. O elemento ou os elementos seleccionados polo selector denomínanse suxeito do selector.

Estilos de texto

O texto dentro dun elemento disponse no interior da caixa de contido do elemento. Comeza na parte superior esquerda da área de contido (ou na parte superior dereita, no caso de contido en idiomas RTL) e flúe ata o final da liña. Unha vez que chega ao final, pasa á seguinte liña e volve fluír ata o final. Este patrón repítese ata que todo o contido queda colocado dentro da caixa.
